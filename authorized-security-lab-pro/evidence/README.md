# Evidence Directory

Store only the minimum evidence required to substantiate findings.

Recommended naming:
YYYYMMDD_HHMMSS_ASSET_FINDINGTYPE.ext

Examples:
- 20260929_221500_LAB-01_headers.txt
- 20260929_222000_LAB-01_screenshot.png

Rules:
- Redact secrets and personal data.
- Do not store credentials.
- Do not collect unrelated files.
- Keep evidence confidential.
- Delete evidence according to the approved retention period.
